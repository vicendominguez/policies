# Privacy Policies

This repository contains privacy policies for my apps.

## Apps

- [HomeCare Tracker](home-maintenance-tracker/) - Home maintenance task manager

## Structure

```
policies/
├── home-maintenance-tracker/
│   ├── privacy-policy.html (English)
│   ├── politica-privacidad.html (Español)
│   └── index.html (redirect)
```

## URLs

After deploying to GitHub Pages:

- English: `https://your-username.github.io/policies/home-maintenance-tracker/privacy-policy.html`
- Español: `https://your-username.github.io/policies/home-maintenance-tracker/politica-privacidad.html`

## Deployment

1. Create repo `policies` on GitHub
2. Push this content
3. Enable GitHub Pages (Settings > Pages > Source: main branch)
4. Wait 1-2 minutes for deployment
